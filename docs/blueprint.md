# **App Name**: PixelPort Studio

## Core Features:

- Dynamic Header Navigation: Implement the main navigation bar with links to 'Work', 'Services', 'About', 'Contact', 'Lab', and a distinct 'Let's Talk' call-to-action.
- Custom Brand Mark Display: Accurately display the unique 'dh' logo or brand mark in the header section.
- Hero Introduction Text Display: Render the prominent 'HEY!' heading and the detailed introductory paragraph about the portfolio owner in the hero section.
- Interactive Visual Avatar: Showcase the bespoke illustration of the portfolio owner, designed to be visually engaging and central to the hero section.
- Custom Theme Toggle: Integrate the 'GOLD' themed toggle switch at the bottom of the hero section, implying a stylistic or feature-based mode change.
- AI Intro Content Assistant: A tool that generates variations of the introductory 'HEY!' text and descriptive paragraphs, allowing the portfolio owner to tailor their message for different platforms or audiences.

## Style Guidelines:

- Primary color: A vibrant, electric blue (#3D4DF5) to create a striking and modern visual focal point, especially within the hero section.
- Background color: A deep, almost-black blue (#1C1C22) for the general application background and header, providing a sophisticated, dark canvas that makes the primary blue and content pop.
- Accent color: A warm, dynamic orange (#EB9947) drawn from details in the hero illustration, used for interactive elements and highlights to add an energetic contrast.
- Headline font: 'Space Grotesk' (proportional sans-serif) for its bold, techy, and slightly playful feel, ideal for striking titles like 'HEY!'.
- Body and navigation font: 'Inter' (grotesque-style sans-serif) for a modern, objective, and highly legible text, suitable for navigation links and descriptive paragraphs.
- Custom icons and brand elements (like the 'dh' logo and 'GOLD' toggle) with a flat, clean, and distinct graphic style matching the overall modern aesthetic.
- Asymmetrical two-column hero layout with the textual content box on the left and a large custom illustration on the right, balanced within generous black borders.
- Subtle hover effects on navigation items and interactive elements, with gentle fades or slides for content transitions to enhance user engagement without distraction.
